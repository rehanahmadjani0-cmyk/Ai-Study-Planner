
# My AI Study Planner

A simple Python project that helps students plan their
weekly study time and organize their AI learning goals.

## Features

- Collects the student's name and learning goal.
- Accepts study days and daily study hours.
- Calculates total weekly study hours.
- Displays a personalized study schedule.
- Saves the plan to `study_plan.txt`.
- Checks that numeric inputs are valid.

## Requirements

- Python 3
- No external packages required

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python main.py
   ```

   Alternatively, use `python3 main.py`.

4. Answer the questions.
5. Read the generated `study_plan.txt` file.

## Example

If a student studies 3 days per week for 2 hours daily:

Weekly study hours = 3 * 2 = 6 hours.
